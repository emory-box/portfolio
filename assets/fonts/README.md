# Self-hosted fonts

The portfolio uses the original Latin Inter and Nunito variable WOFF2 files.
Greeny's Vietnamese case study adds their Vietnamese subsets under private
CSS family aliases, scoped to `.greeny-case-study`. Other pages, navigation
and the 3D story retain their current font declarations.

Downloaded from the official Google Fonts CSS API on 2026-11-07:

- Inter 100–900, Vietnamese, v20:
  `https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa2pL7SUc.woff2`
- Nunito 200–1000, Vietnamese, v32:
  `https://fonts.gstatic.com/s/nunito/v32/XRXV3I6Li01BKofIOuaBXso.woff2`

Licenses: `Inter-OFL.txt` and `Nunito-OFL.txt`, supplied by
`google/fonts` (`ofl/inter/OFL.txt`, `ofl/nunito/OFL.txt`).
All visitor requests use the local files. No Google Fonts runtime request.
