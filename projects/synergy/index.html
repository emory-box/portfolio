Overview

This is a self-initiated project created out of my passion for the education sector, developed over 3 months.

Synergy is designed to enhance the university experience by providing seamless access to essential academic tools and communication features.

Minh Huy

Age: 20
Second-year university student
Tech Savviness: High

Pain Points

  • Struggles with managing class schedules and assignment deadlines.
  • Finds it difficult to navigate campus efficiently.

Goals & Needs

  • A centralized app to track class schedules, exams, and grades in real-time.
  • An interactive map to find buildings and estimated travel times.

Pain Points

Features ideation

Synergy/User research

Account, news & meeting discovery
Read diagram description

Account contains student information (student ID, photo, faculty, academic year, program type and log out) and settings. Settings include emergency contact information, department submission and notification types: request submitted/result, meeting reminder, class reminder and educational announcement. News has search suggestions, delete search, results and 404; cards contain title, subtitle, date posted, views and photo. News filters cover events (festival, career, campaigns, conferences, competition), scholar (academics, support, external), education (facility, policy), highlight, most viewed and reset. Meeting discovery has a card (title, tag, two-level categories, date, speaker, participant, photo), the same search states, and filters: skill (technical, soft, creative), academic support (study sessions, exam preparation, mentoring), university (training, programs, career), highlight, high attendance and upcoming.

Edit meetings, calendar & check-in
Read diagram description

Edit Meeting includes edit/remove, meeting-card information, Waiting/Approved/Declined states and a confirmation prompt returning to Created meetings. The course/meeting calendar allows month/date selection, today/current-time/school-day indicators and return to today. Course cards contain name, time, location and attendance: attended, not attended, empty; active/inactive states. Meeting cards contain name, time, online status and speaker. Calendar filters are Exam, Course and Meeting. Check-in has QR scan, Bluetooth on/off and success/failure confirmation (icon, date/time, subject/code, place, OK, Try again/Back and failure reason); history is grouped by current semester with name/time cards.

Facilities, room booking & campus
Read diagram description

Facility branches into Room booking, Photocopy check and Other equipment. Room booking has Book a room and My booking. Book a room supports filters (capacity, equipment), a calendar (month/date, today/current-time indicators, back to today, add time slot, Book), specified room and time, a room card (name, capacity, equipment), and a form (room name, date/time, facility, purpose, terms and conditions, commitment tick, Submit). My booking has Waiting, Approved and Declined states. Find a location on Campus offers Saved/All campus categories, campus name/location/save, filters by region/country/city/district and numbered map locations with a 2D/3D idea. Map branches into search (suggestions, delete, results, 404), location card (name, type, location, number, open hours, room-booking button) and quick suggestions: library, canteen, parking, restrooms and water station.

Scores, attendance, tuition & schedules
Read diagram description

Score supports year/semester selection; score cards have name/code, four types, three placeholders and one main value. The overall summary includes GPA, credits taken and courses completed. Check-in contains Bluetooth/QR scanning, success/failure prompts and current-semester history. Pay tuition fee has a list grouped Upcoming/Paid/Overdue, tuition cards with name and subject details (name, credits, individual/overall amount), amount in numbers and words, Pay/Paid/Overdue states, Full/Instalments options and confirmation. Schedule covers exam (name/code, date/time, location), study (name/code, date/time, location, end date) and holiday (name, start/end date).

Taskflows

Synergy/User research

Search news & search meetings
Read diagram description

News: Open app → Home → Choose view all news → List of News. For specific news: Search for a name → Search suggestions → Choose a Suggestion or Choose search → Search Result → Choose a news → Detail a New. For news of the same type: Choose Filter → Filter → Apply Filters → Filter suggestions → Choose a news → Detail a New. Meetings follows Open app → Home → Choose Meetings tab → Meetings, then keyword Search suggestions or Filter/Apply Filters branches, converging on Choose a meeting → Detail a meeting.

Register a meeting & create a meeting
Read diagram description

Registration: Open app → Home → Choose Meetings tab → Meetings → Choose a meeting → Meeting Detail (Have not registered) → Read the meeting → Choose Register → Pop-up Confirmation → OK → Meeting Detail (Registered). Create: Open app → Home → Choose Meetings tab → Meetings → Choose Manage Meetings → Manage meetings → Choose Create a Meeting → Create meeting sheet → Fill in info → Choose create → Pop-up Confirmation → Create? No returns to the sheet; Yes opens the created prompt, then View: Yes opens Created Meetings; No returns to Meetings.

Edit a meeting, pay fees & view scores
Read diagram description

Edit: Open app → Home → Choose Meetings tab → Meetings → Choose Created meetings → Created meetings → Choose edit 1 meeting → filled Create meeting sheet → Edit info → Confirm → Pop-up Confirmation → OK → Prompt: meeting created. Fees: Open app → Home → Choose Facility → Fee; optional View detail → Fee Detail; Choose Pay → Payment Option Sheet → Pay → Confirmation Screen → Confirm. Scores: Open app → Home → Choose Score → Score.

Attendance check-in & calendar
Read diagram description

Attendance: Open app → Home → Choose Attendance → App access bluetooth? No shows a Bluetooth permission prompt, then User close prompt & give permission returns to the access decision. Yes proceeds to Scan CAM → Scan QR → Successful? Yes opens Successful Prompt. No opens Fail Prompt → Re-try, returning to Scan CAM. Calendar: Open app → Home → Choose Calendar → Calendar → Change month → Change date; then View detail a subject → Detail subject, or View detail a meeting → Detail a meeting.

Book a room & find directions
Read diagram description

Booking: Open app → Home → Choose Facility → Facility → Choose Room Booking → Choose Book a room → Facility (Room booking). Find available room uses Date & time input; find available time uses Room name input; both lead to Search → List of rooms → Filter (location, capacity) → Choose the room → Time defined? Yes opens Book Form. No opens Room schedule → Change date → Choose a slot → Choose book → Book Form. Filled form → Submit → Prompt: Confirm. Directions: Open app → Home → Choose Facility → Campus → Choose Campus → Map & Search → Choose Get direction → App access GPS? Yes displays Map with location direction. No shows location permission prompt, then user closes the prompt and retries the permission check.

Icon & Graphic

Synergy/Design system

Read diagram description

System icons cover navigation, calendar, clock, share, meeting, filters, bookmarks, accounts, search, notifications, check-in, visibility, edit and delete. Four subject symbols distinguish General, Selective, Specialization and Capstone. Location pins identify buildings, dining, parking, waste disposal and water. Meeting graphics use the original geometric motifs. Service graphics represent Calendar, Fee, Score, Campus, Facility and Check-in.

Button

Synergy/Design system

Read diagram description

Primary: main action button for key interactions. Secondary: supports navigation or optional actions. Highlight: emphasizes important non-primary actions. Cancel: dismisses or cancels an action. Large primary uses 8px vertical and 16px horizontal padding; small uses 4px and 8px.

Components

Navigation has Home, Meetings and Account, with an azure selected item. Text fields show empty, filled, focused and invalid states, visibility icons and an Enter Verification Code input.

Calendar supports week/month layouts and Today. Headers have back, filter and share variants. Marketing banner links to an event. Semester fee shows due date, amount and Paid state. Subject fee carries a title, credits and amount. Room cards show capacity, equipment, date and time, study-group purpose and remove action. Segments are Waiting, Approved and Declined. Category and tag components show selected and disabled variants.

News card: highlighted status, posting date and title. Meeting card: date, speakers, category, title and participant count. Calendar cards distinguish subject/meeting, attendance and inactive states. Location card: name, distance, opening status and closing time. Campus card: image, name, location and bookmark.
