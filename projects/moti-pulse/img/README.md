# Moti-Pulse source assets

Source: the owner's `D:\Web-portfolio\Raw\Moti-pulse\Desktop - 2.jpg`
(1910 × 32768 px). The raw board stays outside the repository.

The JPEG files are crops of the original research charts, illustrated persona
portraits, function and task-flow diagrams, hand-drawn sketches, interface
screens and phone mockups. They preserve the original design evidence rather
than substitute invented UI or photography. The page's headings, body copy,
research cards, comments, personas, architecture and navigation are HTML/CSS.

The mockup panels use original still images. Hi-Fi also presents eight
owner-supplied screen-recording loops, documented in `../video/README.md`.
Still artifacts are displayed inline without links, hover outlines or zoom
cursors. Research reference links remain available in the case-study text.

The six task-flow diagrams use the supplied `flow-*.svg` files in the page.
Function ideation uses the four supplied
`Group-Function-1.svg` through `Group-Function-4.svg` in that order.
All 25 sketches use the supplied SVG files, including `sketch-23.svg`.
The Add Tasks flow uses the owner's updated `flow-tasks.svg`. Image dimensions follow
the supplied SVGs, and the original assets remain unmodified by the page.

`logo-centered.png` is a corrected 55 × 55 crop of the same original header
mark (source rectangle x=41, y=20). It centers the original concentric circles
inside the rounded square in the website header; the artwork is not redrawn.

The owner's latest clarification requires the original content and narrative
order. Demographics use the supplied `Age-pie-graph.svg` and
`location-pie-graph.svg`. Survey bar charts use `bar-1.svg` through
`bar-9.svg` in source reading order, with the supplied `bai-4.svg` at position
4 (its original filename). The first five show pain points; the last four
show solutions. Headings and solution text from the JPEGs are rendered in HTML.
Source percentages remain unchanged, with no inferred counts or values.
The nine bar SVGs are embedded in the HTML with separate grid and column
groups for scroll animation; their original paths and bar dimensions are
preserved. They remain display-only diagrams in the case study.

The pie charts use `*-pie-graph-display.svg` for their on-page animation.
These copies extend each colored edge slightly to cover rendering seams;
the supplied SVGs remain unchanged in this folder.
The Location display copy also aligns the inner vertices to one shared center
at (101.5, 101.5), matching the animation's sweep origin.

Hi-Fi uses the supplied `screen-dashboard.svg`, `screen-mission.svg`,
`Goal.svg` and `Timer.svg`, in that order.
