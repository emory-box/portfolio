# Moti-Pulse — website

| File/thư mục | Mục đích |
| --- | --- |
| `index.html` | Nội dung case study và SVG chart inline để animate từng phần |
| `moti.css` | Layout, theme, contents panel, Hi-Fi |
| `moti.js` | Reveal, chart, contents panel, phát/dừng video theo cuộn |
| `img/` | Asset hiển thị và SVG bằng chứng thiết kế |
| `img/diagrams/` | Sơ đồ sinh từ nguồn authoring, đã restyle |
| `video/` | Tám MP4 và tám poster dùng trong Hi-Fi |

Giữ nguyên nội dung, số liệu, thứ tự section và các nối kết lập luận từ
board gốc. Ảnh chỉ để hiển thị. SVG chart nguồn không tự cập nhật phần đã
nhúng inline trong HTML; phải sửa phần tương ứng và giữ nguyên số liệu.
