How it is built

Three rules that shape every project on this site.

  1. The interface is the evidence

    Each case study pairs readable HTML with original design artifacts and browser interactions.

  2. One system per project

    Every project carries its own palette, type and components, recorded in a DESIGN.md that survives the build.

  3. Static by choice

    No framework, no build step, no tracking. The whole site runs on GitHub Pages and works without JavaScript.
